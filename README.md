# 🏆 Sports Competition Manager

> **Учёт спортивных соревнований** — веб-приложение на Python для организации,
> проведения и анализа спортивных турниров

## 🎯 О проекте

**Sports Competition Manager** — это *веб-приложение на Python*, предназначенное
для **учёта спортивных соревнований**. Система позволяет организаторам создавать
турниры, тренерам — управлять составами команд, а игрокам — просматривать
турнирные таблицы и подавать заявки на вступление в команду.

Проект реализован как **сайт на Python** с использованием **SQL-базы данных**
для хранения информации о пользователях, командах, турнирах и матчах.

### Ключевые идеи

- 🔐 **Регистрация и авторизация** пользователей с разными ролями
- 🎭 **Разграничение прав доступа** — каждая роль видит только свой функционал
- ⚡ **Реальное время** — турнирные таблицы обновляются сразу после внесения результатов
- 🗄 **SQL-база данных** — надёжное хранение всех данных о соревнованиях
- 🌐 **Веб-интерфейс** — работает в любом современном браузере

## 👤 Роли пользователей

При регистрации пользователь выбирает **одну из трёх ролей**:
*организатор*, *игрок* или *тренер*. От выбранной роли зависит доступный
функционал на платформе.

### 🎭 Сравнение ролей

| Роль | Регистрация | Просмотр таблиц | Запрос в команду | Состав команды | Добавление на турнир | Создание турнира | Редактирование турнира | Удаление команды с турнира |
|------|:-----------:|:---------------:|:----------------:|:--------------:|:--------------------:|:----------------:|:----------------------:|:--------------------------:|
| **Игрок** | ✅ | ✅ | ✅ | ❌ | ❌ | ❌ | ❌ | ❌ |
| **Тренер** | ✅ | ✅ | ❌ | ✅ (своей) | ✅ | ❌ | ❌ | ✅ (своей) |
| **Организатор** | ✅ | ✅ | ❌ | ✅ (любой) | ✅ | ✅ | ✅ | ✅ |

> **Важно:** часть функций доступна **только после входа в систему**.
> Гости (неавторизованные пользователи) могут просматривать публичные
> страницы, но не имеют доступа к управлению.

### 🟢 Роль «Игрок»

**Доступные действия:**

1. **Просмотр турнирных таблиц** — в любое время, даже без входа в систему
2. **Запрос на добавление в команду** — доступно *после авторизации*
3. **Регистрация на платформе** — выбор роли при создании аккаунта

**Ограничения:**

- ❌ Не может редактировать составы команд
- ❌ Не может создавать или редактировать турниры
- ❌ Не может добавлять команды на турниры

### 🟡 Роль «Тренер»

**Доступные действия:**

1. **Редактирование состава команды** — управление игроками *своей* команды
2. **Добавление команды на турнир** — регистрация своей команды в соревнованиях
3. **Просмотр турнирных таблиц** — отслеживание положения команды

**Ограничения:**

- ❌ Не может создавать и редактировать турниры
- ❌ Не может удалять команды с турнира
- ❌ Не может редактировать чужие команды

### 🔵 Роль «Организатор»

**Доступные действия:**

1. **Создание турниров** — настройка формата, сроков, правил
2. **Редактирование информации о турнирах** — название, даты, регламент
3. **Добавление команды на турнир** — регистрация участников
4. **Удаление команды с турнира** — исключение участников
5. **Просмотр турнирных таблиц** — контроль хода соревнований
6. **Редактирование турнирных таблиц** — ручная корректировка (например, при снятии очков)
7. **Изменение состава команд** — управление любыми командами

**Ограничения:**

- ⚠️ Большинство функций доступно **только после входа в систему**

## ✨ Функциональные возможности

### 👥 Пользователи и роли

- Регистрация с выбором роли (**игрок**, **тренер**, **организатор**)
- Вход и выход из системы
- Личный кабинет с информацией о профиле
- Разграничение прав доступа в зависимости от роли

### 🏅 Турниры *(только организатор)*

- Создание турниров с настройкой формата
- Редактирование информации: название, даты, место, регламент
- Системы проведения: *круговая*, *кубковая*, *плей-офф*, *смешанная*
- Настройка системы начисления очков

### 👥 Команды

- **Тренер** — редактирование состава *своей* команды
- **Организатор** — изменение состава *любой* команды
- **Игрок** — подача запроса на вступление в команду
- Добавление команды на турнир *(тренер, организатор)*
- Удаление команды с турнира *(только организатор)*

### 📊 Турнирные таблицы

- **Просмотр** — доступен всем (включая гостей)
- **Редактирование** — только организатор
- Автоматический подсчёт очков, побед, поражений, разницы мячей
- Сортировка и фильтрация по различным критериям

### 📅 Матчи

- Расписание игр внутри турнира
- Внесение результатов матчей
- Учёт дополнительного времени и пенальти
- Автоматический пересчёт турнирной таблицы

## 🗄 Архитектура и база данных

### Основные таблицы SQL

| Таблица | Назначение | Ключевые поля |
|---------|-----------|---------------|
| `users` | Пользователи системы | `id`, `username`, `email`, `role` |
| `teams` | Команды | `id`, `name`, `coach_id` |
| `team_members` | Состав команд | `team_id`, `player_id`, `status` |
| `tournaments` | Турниры | `id`, `name`, `format`, `start_date`, `end_date` |
| `tournament_teams` | Участие команд в турнирах | `tournament_id`, `team_id` |
| `matches` | Матчи | `id`, `tournament_id`, `home_team_id`, `away_team_id` |
| `standings` | Турнирные таблицы | `tournament_id`, `team_id`, `points`, `wins`, `losses` |
| `join_requests` | Запросы на вступление | `id`, `player_id`, `team_id`, `status` |

### Связи между таблицами

```
users ──┬── teams (тренер)
        ├── team_members (игрок)
        └── join_requests (игрок)

tournaments ──┬── tournament_teams ── teams
              ├── matches
              └── standings
```

### Схема ролей

| Роль в БД | Значение поля `role` |
|-----------|----------------------|
| Организатор | `organizer` |
| Тренер | `coach` |
| Игрок | `player` |

## 🚀 Установка и запуск

### Требования

- **Python** 3.11 или выше
- **pip** — менеджер пакетов Python
- **Git** — для клонирования репозитория
- Опционально: **PostgreSQL** (для продакшена)

### Шаг 1. Клонирование репозитория

```bash
git clone https://github.com/DarkPlayer8465/Laboratorka.git
cd Laboratorka
```

### Шаг 2. Создание виртуального окружения

```bash
# Windows
python -m venv venv
venv\Scripts\activate

# Linux / macOS
python3 -m venv venv
source venv/bin/activate
```

### Шаг 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 4. Настройка базы данных

```bash
# Применение миграций (создание таблиц SQL)
python manage.py makemigrations
python manage.py migrate
```

### Шаг 5. Создание суперпользователя *(опционально)*

```bash
python manage.py createsuperuser
```

### Шаг 6. Запуск сервера

```bash
python manage.py runserver
```

## 📖 Использование

### 🔹 Регистрация

1. Перейдите на страницу **«Регистрация»**
2. Укажите **логин**, **email**, **пароль**
3. Выберите **роль**:
   - *Игрок* — просмотр таблиц, запросы в команду
   - *Тренер* — управление составом, добавление команды на турнир
   - *Организатор* — полное управление турнирами
4. Нажмите **«Зарегистрироваться»**

### 🔹 Вход в систему

1. Перейдите на страницу **«Вход»**
2. Введите логин и пароль
3. После входа откроется **функционал вашей роли**

### 🔹 Сценарии использования

**Игрок:**
```
Вход → Просмотр турнирных таблиц → Выбор команды → Запрос на вступление
```

**Тренер:**
```
Вход → Создание команды → Редактирование состава →
Добавление команды на турнир → Просмотр таблиц
```

**Организатор:**
```
Вход → Создание турнира → Настройка регламента →
Добавление команд → Внесение результатов →
Редактирование таблицы → Просмотр итогов
```
